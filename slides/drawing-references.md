# React/SVG drawing references

These 18 fictional examples preserve the earlier authoring approach: React/SVG
source, original briefs and reviewed screenshots. Use them for drawing, typography
and layout techniques; **they cannot be imported directly into the editor**.
For editable documents, see the [native gallery](README.md).

To adapt trusted source, follow the [conversion guide](../docs/development.md#reactsvg-drawing-references)
and inspect the result in the canvas. These files are not runnable app routes.
npm includes source and briefs; screenshots remain in the repository and show
the historical browser renders, not export or cross-application fidelity.
