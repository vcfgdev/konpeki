# Landscape slides

Use for presentation pages or a deck, including a single slide. Apply the
[shared guidance](../SKILL.md#before-authoring) and the
[authoring floor](../floor.md); the brief overrides format defaults below.

- Start with the theme's 16:9 `presentation` preset when the destination
  supplies no size. Honor a requested ratio and keep deck dimensions consistent
  unless a mixed-size deliverable is intentional.
- Build a reading sequence: each page advances the explanation rather than
  repeating the previous page's conclusion. Do not impose a fixed opening,
  agenda, or closing-page formula on every brief.
- Give a page one main point and enough evidence to support it. A takeaway
  headline is useful; a giant headline that displaces the explanation is not.
- Compose for viewing at a distance. Start with the preset's resolved type
  roles, then check the intended view; the small-text floor is not a body-copy
  target. Keep sources, units, and caveats legible too.
- Prefer short, coherent text groups over document-length paragraphs. Use a
  diagram, chart, image, or comparison when it carries the explanation; do not
  require a visual on every page or flatten every idea into matching cards.
- When content exceeds a page, redistribute it into a meaningful sequence
  rather than shrinking everything. Respect an explicit page-count constraint.
- Keep recurring type, margins, and semantic colors consistent while varying
  composition when the content changes. A title page need not dictate every page.

Review the deck at fitted size and in reading order. Check that comparisons use
the same criteria and scales, and that each page remains understandable without
presenter notes. Konpeki delivers static pages, not a presentation player.
